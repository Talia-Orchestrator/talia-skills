# Talia Skills

Public, text-first Talia skill packages. Each package includes `SKILL.md` and any supporting references or assets. The repository preserves the existing specialist library; all 25 current skills are included in the signed public store catalog.

The general shared set is `source-synthesis`, `material-organizer`, `project-brief`, and `deliverable-review`. Five product system skills remain in the desktop core and are not redistributed as marketplace skill packages.

Repository: https://github.com/Talia-Orchestrator/talia-skills

Run npm test to validate the 25 package manifests, entrypoints, and license files. Pull requests use the same secrets-free check.
