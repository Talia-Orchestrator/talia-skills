# guided-plan

Shared Talia skill package. The instruction entrypoint is SKILL.md; this package contains declarative text and supporting reference assets only.

See LICENSE and NOTICE for license and provenance.

## Integrazione

Il testo `SKILL.md` è identico al seed guided-plan 0.1.0 già nel core. La skill
raccoglie requisiti, presenta il piano e attua soltanto dopo conferma; i gate
dell'host restano obbligatori. Il catalogo firmato Store viene aggiornato nella
PR coordinata; non dichiarare disponibilità pubblica prima del suo merge.
Nessun eseguibile o nuova versione dell'app è prodotto da questo pacchetto.
