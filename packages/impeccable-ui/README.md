# Impeccable UI for Talia

Shared UI/UX skill for UIDesigner, adapted from Impeccable 4.8.2. Source and command references are pinned to the revision recorded in provenance.json.

## Capabilities

- UI/UX critique and technical accessibility, responsive and performance audits.
- Typography, layout, color, interaction, onboarding and error-state refinement.
- Existing design-system extraction, documentation and normalization.
- New-work design guidance with explicit product context and visual direction.
- Optional official CLI launchers and checksum metadata for deterministic checks.

The Talia entrypoint maps the upstream instructions to tools available in the host. Package installation adds files and shared skill references. It does not install an engine, enable hooks or register the upstream helper definitions as Talia agents. Automatic after-edit checks require host integration. CLI execution and rendered validation are reported separately from source review.

## Usage

Install or update UIDesigner from the store and review its Impeccable UI dependency. Ask for an audit, critique, polish or a focused command such as typeset, layout, adapt, clarify or harden. The skill can also be installed independently and selected when working on UI.

The existing UI and product instructions remain authoritative. For review requests, deliver findings. For requested edits, implement the scoped changes and inspect the rendered result with the tools actually available.
