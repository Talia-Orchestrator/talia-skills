# plan

Shared Talia skill package. The instruction entrypoint is SKILL.md; this package contains declarative text and supporting reference assets only.

The skill turns an objective into a verifiable plan through a short conversation: it reads available context first, asks only the missing decisions using the host input form protocol, chooses the correct widget for each answer, and presents the plan for explicit approval before execution.
